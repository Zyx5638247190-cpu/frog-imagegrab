# 奶龙取图 / DragonGrab 🐲

一个黄色奶龙主题的 Chrome 扩展（Manifest V3）：在**淘宝 / 天猫 / 京东 / 拼多多商家版**的商品详情页一键提取所有商品图片，
在独立的画廊页里集中预览、勾选、分类筛选，并批量下载为 **PNG / JPG / WebP**，还能一键打包成 ZIP。

> 嗷！奶龙帮你把商品图都叼回来～

---

## 一、文件结构

```
dragongrab/
├── manifest.json          # 扩展清单（MV3）：权限、域名、快捷键、内容脚本声明
├── content.js             # 内容脚本：悬浮按钮 + 图片扫描提取 + 自动分类 + 消息发送 + Alt+S 监听
├── content.css            # 悬浮按钮 / 页面提示气泡样式（黄色奶龙主题）
├── background.js          # Service Worker：跨域取图、格式转码、ZIP 打包、CSV 生成、消息转发
├── gallery.html           # 画廊页：奶龙 Logo + 工具栏 + 网格 + 大图预览层
├── gallery.js            # 画廊逻辑：勾选下载 / 筛选 / 预览 / 相似图合并 / 拖拽排序 / 深色模式
├── gallery.css            # 画廊样式（黄色主题 + 深色模式）
├── icons/                 # 扩展图标（16 / 48 / 128，黄色小奶龙）
└── tools/make_icons.py    # 可选：重新生成图标的脚本（纯 Python，无需第三方库）
```

## 二、安装（新手友好，3 步）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
2. 打开右上角的 **「开发者模式」** 开关。
3. 点左上角 **「加载已解压的扩展程序」**，选择本文件夹 `dragongrab`（注意是包含 `manifest.json` 的那一层）。

安装成功后，工具栏会出现一只黄色小奶龙图标。若图标是灰的或提示错误，请看文末「常见问题」。

## 三、使用

1. 打开任意商品详情页（例如 `item.taobao.com/item.htm?id=...`、`item.jd.com/1000xxxx.html`、`mobile.yangkeduo.com/goods.html?goods_id=...`）。
2. 页面**右下角会出现黄色的「奶龙取图」按钮**（只有详情页会出现，其他页面不显示）。
   - 按钮可以按住拖动到任意位置，位置会自动记住。
3. 点击按钮（或按 `Alt` + `S`）。小奶龙会转圈，同时自动滚动页面把懒加载图片都逼出来。
4. 提取完成后自动打开画廊页，提示「嗷！找到 N 张图啦」。
5. 在画廊页里筛选、勾选，然后下载。

## 四、快捷键 & 功能说明

### 快捷键

| 快捷键 | 作用 | 生效位置 |
| --- | --- | --- |
| `Alt` + `S` | 提取当前页面所有商品图片（不用点按钮） | 商品详情页 / 受支持域名下的任意页面 |
| `←` / `→` | 大图预览时切换上一张 / 下一张 | 画廊页预览窗口打开时 |
| `Esc` | 关闭大图预览 | 画廊页预览窗口打开时 |
| 点击遮罩 / 右上角「关闭」 | 关闭大图预览 | 画廊页 |

### 悬浮按钮（商品详情页）

- 胶囊形、黄色渐变、圆角 20px、带阴影，鼠标悬停放大，`z-index: 999999` 保证在最上层。
- 提取中按钮变成「奶龙搬图中…」并转圈，同时禁用点击，避免重复提取。

### 画廊页工具栏

| 控件 | 说明 |
| --- | --- |
| 全选 / 反选 / 全不选 | 针对当前筛选结果批量勾选（默认提取后全部勾选） |
| 文件名前缀 | 默认 `奶龙图_`，可任意改，下载时生效 |
| 保存格式 | PNG（无损，默认）/ JPG / WebP |
| 画质 | 选 JPG / WebP 时出现，40% ~ 100% |
| 已选数量 | 实时显示「已选 3 / 42」 |
| 下载选中 | 逐张转码下载，文件名 `{前缀}{序号}.{后缀}`，序号补零（`奶龙图_001.png`） |
| 打包下载全部 | 打包成 `dragongrab.zip` 下载（有勾选时打包勾选项，没勾选时打包当前可见全部） |
| 导出CSV | 导出清单（序号 / 分类 / 宽高 / 相似图数量 / 图片地址 / 来源页面），带 BOM，Excel 打开不乱码 |
| 分类标签（加分项） | 「全部 / 主图 / 细节图 / SKU图」自动分组，点击切换筛选，标签上显示数量 |
| 最小宽度滑块（加分项） | 100 ~ 1000px 实时过滤小图，左侧显示当前阈值 |
| 相似图合并（加分项） | 用感知哈希（dHash）识别同一张图的不同尺寸 / 轻微裁剪版本并合并，卡片标注「已合并N张相似图」 |
| 按尺寸排序 | 按像素面积从大到小重排 |
| 深色模式（加分项） | 右上角一键切换，偏好会记住 |
| 清空 | 清空列表和提取历史（不会删除已下载到本地的图片文件） |

### 卡片上的操作

- **点击缩略图** → 全屏大图预览（顶部奶龙 Logo，底部显示「第 3 / 42 张 · 800×800 · 主图 · 来源 img」）。
- **右上角复选框** → 勾选 / 取消。
- **复制链接** → 把图片原始地址复制到剪贴板，按钮变成「已复制」。
- **预览** → 与点击缩略图相同。
- **鼠标悬停** → 旁边弹出 2 倍大小的悬浮预览图（自动避让屏幕边缘）。
- **拖拽卡片** → 调整顺序，下载编号会按新顺序生成。

### 底部历史记录

显示最近一次提取的时间、图片总数、累计提取次数和来源商品标题，数据存在 `chrome.storage`，刷新页面不丢。

## 五、实现说明（为什么这么设计）

- **提取来源**：`<img>` 的 `src` / `currentSrc` / `srcset`，`data-src`、`data-lazy-src`、`data-original`、`data-ks-lazyload`（淘宝）、`data-lazy-img`（京东）等 16 种懒加载属性，`<picture><source srcset>`，元素 `background-image`，以及 `og:image`。
- **过滤规则**：`svg`、`base64`（`data:`）、`blob:`、1×1 像素、宽高小于 100×100、URL 含 icon/logo/placeholder/sprite/watermark 等关键字的图一律丢弃；站点头尾区域（`header`/`footer`/`nav`）也会排除。
- **大图还原**：自动把缩略图地址还原成原图，例如淘宝 `xxx.jpg_400x400.jpg` → `xxx.jpg`，京东 `/s450x450_jfs/` → `/jfs/`、`/n5/` → `/n0/`，拼多多去掉 `imageView2` 缩放参数。
- **跨域转码**：转码在 Service Worker 里做（`fetch` 取 blob → `createImageBitmap` → `OffscreenCanvas` → `convertToBlob`），绕开页面 CORS 限制；转码失败会自动降级为「按原格式直接下载」并在提示里说明。
- **ZIP 打包**：**没有使用 CDN 引入 JSZip**。MV3 的内容安全策略（CSP）禁止加载远程脚本，`importScripts` 外部 CDN 会被拦截；所以 `background.js` 内置了一个纯 JS 的 ZIP 写入器（存储模式 + CRC32，PNG/JPG 本身已压缩，体积几乎无差别），零依赖、离线可用。
- **为什么要画廊页参与下载落盘**：MV3 的 Service Worker 里没有 DOM，也没有 `URL.createObjectURL()`。所以 `background.js` 负责取图与转码并回传数据，`gallery.js` 负责把数据变成 Blob URL 再交给 `chrome.downloads`，这样不受 `data:` URL 长度限制影响。
- **相似图合并**：URL 归一化（去尺寸标记、去查询参数）负责「同图不同尺寸」的合并；dHash 感知哈希负责「轻微裁剪」的近似图合并，汉明距离 ≤ 6 视为同一张。图片数 ≤ 40 时自动执行，更多时点按钮手动触发（省流量）。

## 六、常见问题

**1. 加载扩展时提示「无法加载清单文件」或图标缺失**
请确认选择的是 `dragongrab` 文件夹本身（里面直接有 `manifest.json`），且 `icons/` 三个 PNG 存在。

**2. 图片能提取到，但下载下来仍是 JPG 而不是 PNG**
说明这张图转码失败（一般是图片 CDN 域名没在权限范围内）。解决办法：打开 `manifest.json`，在 `host_permissions` 里补上该 CDN 域名（例如 `"*://*.xxxcdn.com/*"`），重新加载扩展。
如果你希望一步到位，可以把平台域名换成 `"<all_urls>"`，扩展就能取任意域名的图。

**3. 打包 ZIP 报错说体积过大**
出于浏览器消息传递的内存限制，单个 ZIP 上限约 30MB（约 60~100 张原图）。请改用「下载选中」分批下载。

**4. `Alt` + `S` 没反应**
部分页面被别的扩展或网站占用了这个快捷键。可以直接点右下角的「奶龙取图」按钮，或在 `chrome://extensions/shortcuts` 里换一个组合键。

**5. 只在详情页显示按钮，为什么别的页面不显示？**
这是按需求刻意限制的：只有匹配到商品详情页 URL 规则才注入按钮（其他页面仍可用 `Alt`+`S` 提取）。

**6. 图片列表里的图点开是奶龙占位图**
说明这张图地址已失效（CDN 防盗链、商品下架）。奶龙会先尝试回退到页面上实际显示的缩略地址，都失败才显示占位图，不会报错中断。

**7. 批量下载 / 打包时要注意什么**
下载期间请让画廊标签页保持打开（转码和数据组织是在这个页面完成的）。全部下载完成后可以随意关闭。
